## What this site is for

A personal site is the one place on the internet you fully control. No feed
ranking it, no platform deciding it should be shorter, no account required
to read it. That's worth something, and it's worth keeping simple enough
that you'll actually update it.

## Formatting you can use

Everything here is Markdown. Text can be **emphasized**, or *italic*, can
link [somewhere useful](https://developer.mozilla.org/), or can mention a
bit of `inline_code`.

> Block quotes look like this — useful for pulling in someone else's
> sentence without burying it in your own paragraph.

Code blocks are fenced, and you can name the language for highlighting:

```js
function greet(name) {
  return `Hello, ${name}`;
}
```

And lists behave:

- One thing.
- Another thing.
- A third thing, for balance.
