What this site is for

A personal site is the one place on the internet you fully control. No feed ranking it, no platform deciding it should be shorter, no account required to read it. That's worth something, and it's worth keeping simple enough that you'll actually update it.

The whole thing is plain HTML and one stylesheet. There's no build step, no dependencies, and nothing to upgrade. If you can open a file and type, you can publish.

Formatting you can use

Ordinary things work the way you'd expect. Text can be emphasized, can link somewhere useful, or can mention a bit of inline_code.

Block quotes look like this — useful for pulling in someone else's sentence without burying it in your own paragraph.

Code blocks are scrollable rather than wrapped:

function greet(name) {
  return `Hello, ${name}`;
}

And lists behave:

  • One thing.
  • Another thing.
  • A third thing, for balance.

Writing the next one

Copy blog/_template.html, rename it, fill in the title and date in the three or four places they appear, then add a matching entry to blog/index.html. It's a manual step, and that's the tradeoff for having no build system at all.
